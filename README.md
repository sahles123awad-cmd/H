# يلا وصل — Yalla Wassel

نظام إدارة توصيل عربي بالكامل (RTL) مصمم خصيصاً للسوق الأردني. يربط بين المدراء، السائقين، والعملاء في منصة واحدة.

---

## 🌟 المميزات الرئيسية

### للمدير (Manager)
- **لوحة تحكم شاملة** — متابعة الطلبات، السائقين، والإيرادات في الوقت الحقيقي
- **إدارة الطلبات** — إنشاء، تعيين، تتبع، وإلغاء الطلبات
- **إدارة السائقين** — متابعة الحالة، الموقع، والأداء
- **تقارير وتحليلات** — إيرادات يومية/أسبوعية/شهرية، متوسط قيمة الطلب، أكثر السائقين نشاطاً
- **خرائط حية** — عرض مواقع جميع السائقين والطلبات على الخريطة
- **إدارة المناطق** — تخصيص مناطق العمل لكل سائق
- **جدولة العمل** — مواعيد الدوام وطلبات الإجازة
- **شكاوى وتقييمات** — متابعة شكاوى العملاء وتقييماتهم

### للسائق (Driver)
- **استلام الطلبات** — تنبيهات فورية بالطلبات الجديدة في منطقته
- **ملاحة GPS** — توجيه مباشر لموقع الاستلام والتسليم
- **محفظة الأرباح** — متابعة الأجور اليومية والشهرية
- **نظام النقاط والشارات** — مكافآت للأداء المتميز
- **رسائل وإشعارات** — تواصل مباشر مع الإدارة
- **طلبات الإجازة** — تقديم طلبات إجازة مع موافقة المدير

### للعميل (Customer)
- **طلب توصيل سريع** — إنشاء طلب بثلاث خطوات
- **تتبع حي** — موقع السائق على الخريطة لحظة بلحظة
- **تاريخ الطلبات** — مراجعة كل الطلبات السابقة
- **فاتورة PDF عربية** — طباعة وتحميل فواتير منسقة بالعربية
- **تقييم الخدمة** — تقييم السائق والخدمة بعد كل طلب
- **شكاوى** — تقديم شكوى مع متابعة حالتها

## 🛠 التقنيات المستخدمة

| الطبقة | التقنية |
|--------|---------|
| **Frontend** | React 18 + Vite + TypeScript |
| **UI** | Tailwind CSS + shadcn/ui (Radix UI) |
| **خط عربي** | Cairo (Google Fonts) |
| **خرائط** | Leaflet + OpenStreetMap |
| **حالة/بيانات** | TanStack Query (React Query) |
| **توجيه** | Wouter |
| **Backend** | Node.js 24 + Express 5 |
| **قاعدة البيانات** | PostgreSQL + Drizzle ORM |
| **تحقق** | Zod (`zod/v4`) + `drizzle-zod` |
| **عقد API** | OpenAPI 3.1 + Orval (codegen) |
| **مصادقة** | Session-based + HMAC-SHA256 password hashing |
| **بناء** | pnpm workspaces + esbuild |

## 🚀 التشغيل المحلي

### المتطلبات
- Node.js 24+
- pnpm 9+
- PostgreSQL (يوفرها Replit تلقائياً عبر `DATABASE_URL`)

### الخطوات

```bash
# 1. تثبيت الحزم
pnpm install

# 2. تطبيق مخطط قاعدة البيانات
pnpm --filter @workspace/db run push

# 3. توليد عقد API (إذا تغيّر OpenAPI)
pnpm --filter @workspace/api-spec run codegen

# 4. تشغيل الخادم (المنفذ 5000)
pnpm --filter @workspace/api-server run dev

# 5. تشغيل الواجهة الأمامية (في نافذة أخرى)
pnpm --filter @workspace/yalla-wassel run dev
```

### متغيرات البيئة المطلوبة

| المتغير | الوصف |
|---------|-------|
| `DATABASE_URL` | رابط اتصال PostgreSQL |
| `SESSION_SECRET` | مفتاح سري لتشفير الجلسات وكلمات المرور |

## 🔒 الأمان

- كلمات المرور مُجزَّأة باستخدام **HMAC-SHA256** مع `SESSION_SECRET`
- الجلسات محفوظة في قاعدة بيانات Postgres (مش في الذاكرة)
- جميع المدخلات تُتحقَّق عبر Zod schemas مُولَّدة من عقد OpenAPI
- لا توجد كلمات مرور أو أسرار في الكود — كلها متغيرات بيئة
