═══════════════════════════════════════════════
🗄️ DATABASE SCHEMA
═══════════════════════════════════════════════

Table: zones
- id, name_ar, name_en, governorate, 
  region (west/east/central/north/south),
  is_active (default true)

Table: users
- id, full_name, phone, email,
  password_hash, role (manager/driver/customer),
  zone_id (FK, for drivers),
  status (available/busy/off),
  avatar_url, created_at, is_active

Table: orders
- id (format: YW-2026-XXXX),
  from_business, from_address, from_zone_id,
  to_customer_name, to_phone,
  to_address, to_zone_id,
  priority (urgent/normal),
  status (pending/assigned/picked/delivered/cancelled),
  driver_id (FK),
  notes, created_at, assigned_at,
  picked_at, delivered_at,
  tracking_token (unique random string for public link)

Table: ratings
- id, order_id (FK), driver_id (FK),
  customer_name, stars (1-5),
  comment, created_at

Table: notifications
- id, user_id (FK), message,
  type (order/system/rating),
  is_read, created_at
